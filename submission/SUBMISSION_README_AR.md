# تسليم Stage 1 بعد التشغيل على اللوحة

1. شغل اللوحة وصور الأدلة الثلاثة الحقيقية، وضع صور PNG بالأسماء الموجودة في `evidence/` (ملف README يشرح المطلوب).
2. اعمل repository عام على GitHub، وارفع كودك وREADME، وارفع صور الأدلة بعد تنقيح الخصوصية. **ملفات evidence مُستثناة من git افتراضيًا**؛ استخدم `git add -f evidence/اسم_الصورة.png` فقط بعد مراجعتها، أو ضعها يدويًا على GitHub.
3. افتح خيطك الشخصي في Discord وانشر جميع روابط الأدلة؛ انسخ الرابط الدائم.
4. انسخ ملف `showcase/RDK-X5-EdgeVision-Ignite.md` إلى Fork من مستودع Winter الرسمي داخل `projects/`، بعد تعبئة البيانات الفعلية واحترام النموذج الرسمي، وافتح PR.
5. املأ `submission/stage1_links.json` برابط مستودعك ومنشور Discord وPR وإصدار الصورة واسم الكاميرا واللوحة.
6. نفّذ `python3 scripts/08_verify_submission.py` وتأكد أن النتائج لا تتضمن مفقودات. **الاختبار لا يتحقق من صحة الأدلة أو فتح الروابط**؛ افعل ذلك بنفسك من متصفح غير مسجل.
7. الفيديو غير إلزامي للمرحلة الأولى؛ راجع `docs/VIDEO_REQUIREMENTS_AND_SHOTLIST_AR.md`.
